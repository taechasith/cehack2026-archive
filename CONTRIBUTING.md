# Contributing

Thank you for helping keep the 67HACK archive accurate and useful.

## Project corrections

If you are a project author or team member, open a **Project record correction** issue and include:

1. The stable submission ID, such as `CEHACK-2026-014`.
2. The exact current text or link.
3. The corrected value.
4. A public source or a clear explanation of your relationship to the team.

Never post email addresses, phone numbers, private Drive links, access tokens, API keys, or private team conversations.

## Pull requests

For direct data changes:

1. Edit only the relevant object in `data/projects.json`.
2. Preserve the submission ID.
3. Keep participant wording faithful and neutral.
4. Use HTTPS for public links.
5. Run `npm test` before opening the pull request.

The archive does not assign tracks, awards, rankings, or institutional affiliations without an official verifiable source.

## New material

Pitch decks, screenshots, and source code should remain in the author's own repository or platform. This archive normally links to those materials instead of copying them, which preserves ownership and project-specific licensing.

## Style

- Use the official event name exactly as written in the README.
- Credit people by the names they submitted or later confirmed.
- Avoid promotional claims that cannot be verified.
- Separate source code, live demos, and pitch material.
- Record inaccessible links as unavailable rather than deleting historical evidence.
