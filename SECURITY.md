# Security Policy

This repository is a static archive and does not accept or require secrets.

## Reporting

If you find a vulnerability in the archive interface, report it privately to the repository owner through a verified public contact channel. Do not include personal participant data in a public issue.

Security problems in a linked participant project should be reported to that project's maintainers according to its own security policy. This archive does not maintain or deploy participant code.

## Supported version

Only the current `main` branch of this archive is maintained.
